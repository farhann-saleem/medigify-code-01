Question: Sharpey fibers are composed of:
A) collagen type I
B) collagen type II
C) collagen type III
D) collagen type IV
E) collagen type V
Correct Option: A
Explanation:
Correct (A): Sharpey fibers are heavy bundles of periosteal collagen type I that anchor tendons, ligaments, or the periodontal ligament directly into the mineralized matrix of bone.
Incorrect (B): collagen type II is incorrect because type II collagen is localized almost exclusively within hyaline and elastic cartilages.
Incorrect (C): collagen type III is incorrect because type III collagen forms delicate reticular networks rather than dense, structural anchoring bundles.
Incorrect (D): collagen type IV is incorrect because type IV collagen forms the amorphous meshwork found within basal laminae.
Incorrect (E): collagen type V is incorrect because type V collagen is a minor regulatory fibrillar collagen that associates with type I rather than forming large independent anchoring bundles.
